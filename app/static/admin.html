🛬 Flugplätze (Ergänzungen)

Plätze, die in der Standard-Datenbank (airportsdata) fehlen — z. B. Segelfluggelände ohne offizielle ICAO-Kennung — oder deren Koordinaten dort nachweislich falsch sind. Ein hier eingetragener Code überschreibt airportsdata. Ist der Code bereits bekannt, wird vor dem Überschreiben eine Bestätigung eingeblendet (Schutz gegen versehentliche Duplikate). Breitengrad/Längengrad können leer bleiben, wenn der Code schon bekannte Koordinaten hat (airportsdata oder ein bestehender Eintrag hier) — dann reicht z. B. nur ein größerer Radius (Großflughäfen wie EHAM/Schiphol, deren Abhebepunkt weiter als der Standardradius vom Referenzpunkt entfernt liegen kann).

🔍 Erkennungslücken (Start/Landung)

Flüge, deren GPS-Start oder -Landung trotz bekanntem Flugplan fehlt — meist ein Hinweis auf einen fehlenden Flugplatz oben. Die Prüfung rechnet den GESAMTEN Flugbestand neu durch und ist deshalb teuer (mehrere Sekunden) — sie lädt daher NICHT automatisch beim Öffnen dieser Seite, sondern nur auf Klick. Wird ein Platz ergänzt, verschwindet der betroffene Flug beim nächsten „Aktualisieren". „Geprüft" blendet einen Einzelfall dauerhaft aus, wenn er KEIN Datenfehler ist (z. B. Absturz oder abgerissene Aufzeichnung).
